# Customer Churn & Revenue Optimization Analysis

## Overview

Analysis of customer churn patterns using Excel, SQL, and Python.

## Business Problem

The objective is to identify customer segments associated with higher churn and provide business recommendations for improving customer retention.

## Tools Used

- Excel
- PostgreSQL
- Python
- Pandas
- Matplotlib

## Analysis

### Excel
- Overall churn
- Churn by contract
- Churn by tenure
- Churn by monthly charges
- Churn by internet service
- Churn by payment method

### SQL
- Customer churn analysis
- Churn by contract
- Churn by customer/service characteristics

### Python
- Churn analysis
- Data cleaning
- Grouping and filtering
- Visualization

## Key Findings

- Overall churn rate: 26.54%
- Month-to-month customers had a 42.71% churn rate.
- Customers with 0–12 months tenure had a 47.68% churn rate.
- Fiber optic customers had a 41.89% churn rate.
- Electronic check customers had a 45.29% churn rate.

## Business Recommendations

- Improve onboarding for new customers.
- Encourage longer-term contracts.
- Review pricing and value perception for higher-charge customers.
- Investigate service-related issues among high-churn segments.
